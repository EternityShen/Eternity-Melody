# Eternity-Melody

一个基于终端的音乐节奏游戏，使用 Rust 语言开发。

## 功能特性

- 🎵 音乐播放与节奏同步
- 🎹 4 轨道音符下落玩法
- ⚡ 实时判定系统（Perfect/Great/Good/Miss）
- 🖼️ 终端图形界面（基于 Ratatui）
- 🔊 音效反馈系统

## 技术栈

- **Rust 2024** - 编程语言
- **Ratatui** - 终端 UI 框架
- **Crossterm** - 终端控制
- **Rodio** - 音频播放
- **Serde + TOML** - 谱面解析

## 游戏玩法

### 按键说明

| 按键 | 轨道 |
|------|------|
| S    | 轨道 1 |
| D    | 轨道 2 |
| J    | 轨道 3 |
| K    | 轨道 4 |
| Esc  | 退出游戏 |

### 判定规则

- **Perfect**: ±45ms 误差，+10 分
- **Great**: ±90ms 误差，+8 分
- **Good**: ±150ms 误差，+5 分
- **Miss**: 超过 150ms 或未按，-2 分
